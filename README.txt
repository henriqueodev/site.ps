SITE FRONT-END — SHAYLLA CORREA | PSICÓLOGA CLÍNICA

Arquivos:
- index.html: estrutura e conteúdo do site
- style.css: layout responsivo, cores, tipografia e estilos
- script.js: menu mobile, seleção de sentimentos, contador, navegação de depoimentos e painel de contato
- assets/: imagens recortadas das referências fornecidas

Como abrir:
1. Extraia o ZIP para uma pasta.
2. Abra index.html no navegador. Para desenvolver, recomenda-se usar a extensão Live Server no VS Code.

Observações importantes:
- O projeto é somente front-end. O formulário de desabafo não envia nem armazena informações; isso é informado na própria página.
- O e-mail, CRP, formação e depoimentos exibidos são dados de demonstração presentes na proposta visual e precisam ser confirmados/substituídos pela profissional antes de publicar.
- Para publicar de verdade, conecte o formulário a um backend seguro, implemente consentimento, política de privacidade e controles adequados à LGPD. Não use o formulário demonstrativo para coletar relatos reais.
- As imagens fornecidas são referências de layout; algumas áreas foram recortadas para reutilização como imagens do site.
